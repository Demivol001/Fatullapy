# Fattula Web

**Fattula Web** — мой личный сайт-портфолио, созданный для того, чтобы собирать и показывать свои проекты, а также делиться тем, чему я учусь и чему научился.

Здесь я хочу выкладывать:

- Свои учебные и личные проекты;
- Программы, которые пишу на C++;
- Проекты, связанные с сетями и системным администрированием;
- Заметки о том, что я изучаю и какие навыки осваиваю;
- Идеи, эксперименты и будущие проекты.

Сайт задуман как моё цифровое резюме: вместо обычного документа здесь можно посмотреть мои работы, прочитать о проектах и проследить мой прогресс в программировании и IT.

## Что будет на сайте

- **Проекты** — описание моих работ, технологий и результатов;
- **Посты** — короткие записи о том, чему я научился;
- **Навыки** — что я умею и что сейчас изучаю;
- **Поиск** — быстрый поиск по проектам и записям;
- **Простая навигация** — чтобы легко найти нужный материал.

## Цель проекта

Я хочу, чтобы этот сайт помогал мне:

- Собирать все свои работы в одном месте;
- Показывать свой опыт потенциальным работодателям или преподавателям;
- Лучше понимать, чему я уже научился и куда двигаться дальше;
- Делиться полезными материалами и своими идеями.

## Технологии

Проект сделан на **Next.js** и опубликован через **GitHub Pages**.

## Как посмотреть сайт

Сайт доступен по ссылке:

https://virus-momentx.github.io/fattula-web/

## Как запустить локально

```bash
npm install
npm run dev
```

После запуска открой в браузере:

```text
http://localhost:3000
```
